# CurseForge project fields

## Name

Soul Shards Forever (SSF)

## Summary

Soul Shard cap for warlocks on WoW Forever. Set how many shards to keep; one press of a key, a macro line or a button deletes one shard over the cap. Count on your bag bar, glow when you're running low, nothing else.
